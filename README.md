# Titan Voxel Engine

A voxel engine written in Rust using `wgpu` for rendering.

## Features
*   Voxel chunk rendering
*   Greedy meshing (top faces)
*   Texture arrays
*   Lua scripting integration

## Requirements
*   Rust 2021 edition
*   Vulkan/Metal/DX12 compatible GPU

## Running
```bash
cargo run
```
