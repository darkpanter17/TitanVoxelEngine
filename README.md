# TitanVoxelEngine

Home of **Lost Horizons C++23** — a modern C++23 + Vulkan voxel engine.

The engine lives in [`LostHorizons-CPP23/`](LostHorizons-CPP23/). See its
[README](LostHorizons-CPP23/README.md) for build and run instructions.

Current milestone: **v0.2.1** — free-fly camera, frustum culling, smoother
procedural terrain and multi-threaded chunk generation + meshing, on top of the
v0.1.0 core (engine, Vulkan renderer and window).
